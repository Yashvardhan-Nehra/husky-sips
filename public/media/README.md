# Media

Episode videos are git-ignored because of their size. Before launch, host them on a CDN or a
video platform and update `episodes[].video.src` in `src/config/site.config.ts`.

Expected local files for development (generated from the approved masters with `avconvert`):

- episode-01-540p.mp4
- episode-02-540p.mp4

Posters live in `public/assets/reference/` and are generated by `npm run assets:images`.
